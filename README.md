# MSAN & Mobile FWA Distance calculator Tool

Application Python / Tkinter d'analyse spatiale et d'optimisation de proximité entre les sites MSAN et le réseau Mobile (FWA).

## Fonctionnalités
- **Moteur d'Analyse Spatiale :** Recherche rapide de proximité géométrique via KD-Tree.
- **Export KML Dynamique :** Génération automatique de secteurs et polygones pour Google Earth.
- **Rapports d'Audit Excel :** Nettoyage des coordonnées, validation des données et journalisation des erreurs.
- **Interface Graphique Tkinter :** Mapping dynamique des colonnes et gestion de profils de configuration.
